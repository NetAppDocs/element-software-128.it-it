= Modifica un iniziatore
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
È possibile modificare l'alias di un iniziatore esistente o aggiungerne uno nuovo se non ne esiste già uno.

Per aggiungere un nome account CHAP e credenziali per ogni iniziatore, è necessario utilizzare `ModifyInitiator` Chiamata API per rimuovere e aggiungere l'accesso e gli attributi CHAP.

Vederelink:../api/concept_element_api_about_the_api.html["Gestisci l'archiviazione con l'API Element"] .

.Passi
. Fare clic su *Gestione* > *Iniziatori*.
. Fare clic sull'icona Azioni relativa all'iniziatore che si desidera modificare.
. Fare clic su *Modifica*.
. Immettere un nuovo alias per l'iniziatore nel campo *Alias*.
. Fare clic su *Salva modifiche*.
