= DisabilitaSsh
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi usare il `DisableSsh` metodo per disabilitare il servizio SSH per un singolo nodo di archiviazione.  Questo metodo non influisce sulla durata del timeout del servizio SSH a livello di cluster.



== Parametro

Questo metodo non ha parametri di input.



== Valore di ritorno

Questo metodo ha il seguente valore di ritorno:

|===
| Nome | Descrizione | Tipo 


 a| 
abilitato
 a| 
Lo stato del servizio SSH per questo nodo.
 a| 
booleano

|===


== Richiedi esempio

Le richieste per questo metodo sono simili al seguente esempio:

[listing]
----
{
  "method": "DisableSsh",
  "params": {
      },
  "id" : 1
}
----


== Esempio di risposta

Questo metodo restituisce una risposta simile al seguente esempio:

[listing]
----
{
  "id" : 1,
  "result" : {"enabled": false}
}
----
