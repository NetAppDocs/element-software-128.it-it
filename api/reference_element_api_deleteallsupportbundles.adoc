= Elimina tutti i pacchetti di supporto
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi usare il `DeleteAllSupportBundles` metodo per eliminare tutti i pacchetti di supporto generati con `CreateSupportBundle` Metodo API.



== Parametri

Questo metodo non ha parametri di input.



== Valori di ritorno

Questo metodo non ha valori di ritorno.



== Richiedi esempio

Le richieste per questo metodo sono simili al seguente esempio:

[listing]
----
{
   "method": "DeleteAllSupportBundles",
   "params": {}
  },
  "id": 1
}
----


== Esempio di risposta

Questo metodo restituisce una risposta simile al seguente esempio:

[listing]
----
{
  "id" : 1,
  "result" : {}
 }
}
----
