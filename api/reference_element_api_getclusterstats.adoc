= Ottieni statistiche cluster
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi usare il `GetClusterStats` metodo per recuperare misurazioni di attività di alto livello per il cluster.  I valori restituiti sono cumulativi a partire dalla creazione del cluster.



== Parametri

Questo metodo non ha parametri di input.



== Valore di ritorno

Questo metodo ha il seguente valore di ritorno:

|===
| Nome | Descrizione | Tipo 


 a| 
clusterStats
 a| 
Informazioni sull'attività del cluster.
 a| 
xref:reference_element_api_clusterstats.adoc[clusterStats]

|===


== Richiedi esempio

Le richieste per questo metodo sono simili al seguente esempio:

[listing]
----
{
   "method": "GetClusterStats",
   "params": {},
   "id" : 1
}
----
