= Ottieni informazioni sul cluster
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi usare il `GetClusterInfo` metodo per restituire informazioni di configurazione sul cluster.



== Parametri

Questo metodo non ha parametri di input.



== Valore di ritorno

Questo metodo ha il seguente valore di ritorno:

|===
| Nome | Descrizione | Tipo 


 a| 
clusterInfo
 a| 
Informazioni sul cluster.
 a| 
xref:reference_element_api_clusterinfo.adoc[clusterInfo]

|===


== Richiedi esempio

Le richieste per questo metodo sono simili al seguente esempio:

[listing]
----
{
   "method": "GetClusterInfo",
   "params": {},
   "id" : 1
}
----
