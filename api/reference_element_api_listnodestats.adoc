= ListNodeStats
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi usare il `ListNodeStats` Metodo per visualizzare le misurazioni dell'attività di alto livello per tutti i nodi di archiviazione in un cluster di archiviazione.



== Parametri

Questo metodo non ha parametri di input.



== Valore di ritorno

Questo metodo ha il seguente valore di ritorno:

|===
| Nome | Descrizione | Tipo 


 a| 
nodeStats
 a| 
Informazioni sull'attività del nodo di archiviazione.
 a| 
xref:reference_element_api_nodestats.adoc[nodeStats]

|===


== Richiedi esempio

Le richieste per questo metodo sono simili al seguente esempio:

[listing]
----
{
   "method": "ListNodeStats",
   "params": {},
   "id" : 1
}
----
