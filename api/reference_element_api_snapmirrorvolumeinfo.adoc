= snapMirrorVolumeInfo
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
L'oggetto snapMirrorVolumeInfo contiene informazioni sulla posizione di un volume in una relazione SnapMirror , ad esempio il nome e il tipo.



== Membri dell'oggetto

Questo oggetto contiene i seguenti membri:

|===
| Nome | Descrizione | Tipo 


 a| 
tipo
 a| 
Il tipo di volume. Valori possibili:

* solidfire: il volume risiede su un cluster di archiviazione che esegue il software Element.
* ontap: il volume risiede su un cluster ONTAP remoto.

 a| 
corda



 a| 
ID volume
 a| 
L'ID del volume.  Valido solo se "type" è solidfire.
 a| 
intero



 a| 
server virtuale
 a| 
Il nome del Vserver proprietario di questo volume.  Valido solo se "type" è ontap.
 a| 
corda



 a| 
nome
 a| 
Il nome del volume.
 a| 
corda

|===
