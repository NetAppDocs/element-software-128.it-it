= ResetSupplementalTlsCiphers
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi usare il `ResetSupplementalTlsCiphers` metodo per ripristinare l'elenco predefinito dei cifrari TLS supplementari.  È possibile utilizzare questo metodo sull'intero cluster.



== Parametro

Questo metodo non ha parametri di input.



== Valori di ritorno

Questo metodo non ha valori di ritorno.



== Richiedi esempio

Le richieste per questo metodo sono simili al seguente esempio:

[listing]
----
{
  "method": "ResetSupplementalTlsCiphers",
  "params": {},
  "id" : 1
}
----


== Esempio di risposta

Questo metodo restituisce una risposta simile al seguente esempio:

[listing]
----
{
  "id" : 1,
  "result" : {}
}
----
