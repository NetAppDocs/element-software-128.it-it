= TestLocalConnectivity
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi usare il `TestLocalConnectivity` metodo per effettuare il ping dell'IP del cluster (CIP) di ciascun nodo in un cluster attivo.



== Parametri

Questo metodo non ha parametri di input.



== Valore di ritorno

Questo metodo ha il seguente valore di ritorno:

|===
| Nome | Descrizione | Tipo 


 a| 
dettagli
 a| 
Tempi di risposta ping individuali per ciascun nodo nel cluster locale attivo.
 a| 
Oggetto JSON

|===


== Richiedi esempio

Le richieste per questo metodo sono simili al seguente esempio:

[listing]
----
{
    "method": "TestLocalConnectivity",
    "params": {},
    "id": 1
}
----
