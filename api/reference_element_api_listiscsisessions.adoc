= ElencoISCSISessioni
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puoi usare il `ListISCSISessions` metodo per elencare le informazioni di connessione iSCSI per i volumi nel cluster.



== Parametri

Questo metodo non ha parametri di input.



== Valore di ritorno

Questo metodo ha il seguente valore di ritorno:

|===
| Nome | Descrizione | Tipo 


 a| 
sessioni
 a| 
Informazioni su ciascuna sessione iSCSI.
 a| 
xref:reference_element_api_session_iscsi.adoc[sessione]

|===


== Richiedi esempio

Le richieste per questo metodo sono simili al seguente esempio:

[listing]
----
{
   "method": "ListISCSISessions",
   "params": {},
   "id" : 1
}
----
