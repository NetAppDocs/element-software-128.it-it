= errore
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
L'oggetto errore contiene un codice di errore e un messaggio se si verifica un errore durante una chiamata al metodo.  Tutti gli errori generati dal sistema hanno il codice di errore 500.



== Membri dell'oggetto

Questo oggetto contiene i seguenti membri:

|===
| Nome | Descrizione | Tipo 


 a| 
codice
 a| 
Il codice numerico utilizzato per identificare l'errore.  Tutti gli errori generati dal sistema restituiscono il codice 500.
 a| 
intero



 a| 
nome
 a| 
Identificatore univoco per l'errore specifico che si è verificato.  Ogni metodo restituisce un set documentato di errori, ma è necessario essere preparati a gestire anche errori non riconosciuti.
 a| 
corda



 a| 
messaggio
 a| 
Una descrizione dell'errore, eventualmente con ulteriori dettagli.
 a| 
corda

|===
