= Impostare le zone per i nodi Fibre Channel
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Quando si crea un nuovo cluster con nodi Fibre Channel e nodi di archiviazione SolidFire , gli indirizzi WWPN (Worldwide Port Name) per i nodi sono disponibili nell'interfaccia utente Web.  È possibile utilizzare gli indirizzi WWPN per suddividere in zone lo switch Fibre Channel.

I WWPN vengono registrati nel sistema quando si crea un nuovo cluster con nodi.  Nell'interfaccia utente Element, puoi trovare gli indirizzi WWPN nella colonna WWPN della scheda Porte FC, a cui puoi accedere dalla scheda Cluster.
