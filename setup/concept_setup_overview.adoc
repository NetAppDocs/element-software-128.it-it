= Scopri come impostare l'archiviazione
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
A questo punto dovresti aver installato l'hardware.  L'hardware include anche il software Element.

Successivamente, dovrai configurare il sistema di archiviazione per il tuo ambiente.  È possibile configurare un cluster con nodi di storage o nodi Fibre Channel e gestirlo tramite il software Element dopo aver installato e cablato i nodi in un'unità rack e averli accesi.

image::../media/sf_and_element_workflow_for_setup_shorter_workflow.png[Diagramma del flusso di lavoro di configurazione]

.Passaggi per configurare l'archiviazione
. Seleziona una delle seguenti opzioni:
+
** link:../setup/concept_setup_configure_a_storage_node.html["Configurare il cluster con nodi di archiviazione"]
+
È possibile configurare un cluster con nodi di storage e gestirlo tramite il software Element dopo aver installato e cablato i nodi in un'unità rack e averli accesi. È quindi possibile installare e configurare componenti aggiuntivi nel sistema di archiviazione.

** link:../setup/concept_setup_fc_configure_a_fibre_channel_node.html["Configurare il cluster con nodi Fibre Channel"]
+
È possibile configurare un cluster con nodi Fibre Channel e gestirlo tramite il software Element dopo aver installato e cablato i nodi in un'unità rack e averli accesi. È quindi possibile installare e configurare componenti aggiuntivi nel sistema di archiviazione.
