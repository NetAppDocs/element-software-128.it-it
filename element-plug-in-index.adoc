= Plug-in NetApp Element per vCenter Server
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
NetApp Element Plug-in per vCenter Server fornisce un plug-in all'interfaccia VMware vSphere che consente di gestire e monitorare i cluster di storage che eseguono il software NetApp Element .

Per ulteriori informazioni su Element Plug-in per vCenter Server, vedere https://docs.netapp.com/us-en/vcp/index.html["Documentazione del plug-in NetApp Element per vCenter Server"^] .
